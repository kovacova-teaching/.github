# Tina Kovacova · Teaching

Demos and course material from the LLMOps and MLOps sessions I lead for working professionals, including Great Learning's *Generative AI for Business with Microsoft Azure* program.

Each repo is built to be walked through live: small enough to follow in a session, real enough to show how the pieces fit in production.

My own projects are on my profile: **[github.com/kovacova](https://github.com/kovacova)** · [kovacova.ca](https://kovacova.ca) · [LinkedIn](https://www.linkedin.com/in/kovacova/)

## Featured demos

| Demo | What it shows | Stack |
|---|---|---|
| [**Visual search RAG with GenAIOps**](https://github.com/kovacova-teaching/visual-search-rag-genaiops) | Image-to-product search with prompt-injection and PII guardrails, MLflow tracing and evals | Azure OpenAI, Azure AI Search, ChromaDB, MLflow |
| [**Supply-chain LLMOps case study**](https://github.com/kovacova-teaching/genai-msft-week-13-llmops) | Plain-English questions become Python or SQL; an LLM judge checks the code before it runs | FastAPI, Streamlit, DuckDB, Ragas, Azure OpenAI |
| [**Azure ML churn pipeline with CI/CD**](https://github.com/kovacova-teaching/azureml-churn-cicd) | Training to a managed online endpoint, every step driven by GitHub Actions | Azure ML, GitHub Actions, MLflow, scikit-learn |
| [**LLMOps: monitoring, CI/CD and governance**](https://github.com/kovacova-teaching/gen-ai-msft-w14-monitoring-cicd-gov) | Taking a RAG app from prototype to a monitored, governed service | Prompt Flow, Azure AI Foundry, ACR, App Service |
